¿Qué es EvoClinica?

EvoClinica es un sistema diseñado para facilitarle la gestión de información a los trabajadores del Hospital de Clinicas, permitiendo un acceso y modificacion mas rapida y sencilla para el personal del hospital.

Módulos del sistema

Documentación

Permite acceder a la documentación relacionada con los pacientes para modificarla.

Ambulancias

Permite gestionar y realizar el seguimiento de los traslados de ambulancias.

Objetivo del sistema

El objetivo de EvoClinica es organizar la información del hospital y facilitar el acceso a los diferentes módulos del sistema, permitiendo una mejor gestión para un mejor funcionamiento del hospital.
